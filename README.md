# پروپوزال دپارتمان خلاقیت تایم‌کوچ

پروپوزالی برای راه‌اندازی «دپارتمان خلاقیت» در آکادمی تایم‌کوچ؛ همراه با رزومه و گالری خلاقیت.

**مشاهدهٔ سایت:** https://amirpvf.github.io/creativity-department-proposal/

## بخش‌ها

- **پروپوزال:** خاستگاه ایده، کارت‌های «چه می‌شد اگر…؟» و حوزه‌های فعالیت
- **رزومه:** سوابق، مدارک و نسخهٔ PDF قابل دانلود
- **گالری خلاقیت:** نسخهٔ آزمایشی ابزارها با دادهٔ نمونه، و دانلود نسخهٔ اصلی هر ابزار
- **راهنما:** شیوهٔ استفاده از همهٔ امکانات سایت

## ساختار پوشه‌ها

| پوشه | محتوا |
|---|---|
| `index.html` | صفحهٔ اصلی سایت |
| `panels/` | نسخهٔ آزمایشی ابزارها |
| `orig/` | نسخهٔ اصلی ابزارها و فایل‌های PDF برای دانلود |
| `certs/` | تصویر مدارک (اطلاعات شناسایی محو شده است) |
| `docs/`، `thumbs/` | تصاویر صفحه‌های پروپوزال‌ها و پیش‌نمایش کارت‌ها |
